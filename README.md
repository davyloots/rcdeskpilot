# R/C Desk Pilot

R/C Desk Pilot (RCDP) is an R/C flight simulator for Windows.

The original project was created as a passion project and developed using a custom game engine written in C#, based on Managed DirectX 9.0c.

This repository contains a **restored and repaired version of the original R/C Desk Pilot project**.

## Restored Version

The project was recovered and repaired to make it functional again on a modern Windows environment.

Several issues were addressed during the restoration process, while preserving the original project and its concept as much as possible.

This restoration is shared with respect for the original creator and his work.

## Original Project

The original RCDP website was:

http://rcdeskpilot.com

The original project required Visual Studio 2015 to compile and used Managed DirectX 9.0c.
